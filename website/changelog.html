Changelog

Every release of Server Operator, from the initial launch to the latest update.

v2.0.1

Glass Harbor

2026-06-12

This release adds real local workspace support, the new serop folder launcher, inline SQL row editing, a glassy terminal-style appearance option, and a much more capable deploy assistant with cleaner chat rendering and project-aware command suggestions.

Local Workspace Mode

  • Added a Local Workspace connection type so you can open a folder from your own machine inside Server Operator without SSH.
  • Local workspaces now support file browsing, terminal access, Docker inspection, compose logs, database tooling, deploy commands, and .serop shortcuts.
  • Added startup folder handoff so launching the app with a folder automatically opens it as a local workspace profile.
  • Added the new serop launcher flow so serop . opens Server Operator directly in the current directory.

Deploy Assistant & Shortcuts

  • Deploy AI chat now returns real answers plus optional runnable commands instead of command-only output.
  • Added response parsing, malformed-tag recovery, model fallback on Groq rate limits, and cleaner command presentation cards.
  • Normalized deploy project paths to absolute remote paths so project switching no longer breaks with relative cd commands.
  • Moved deploy project chips, context, and .serop shortcuts into the main sidebar with accordion-based command editing and direct run actions.

Database Editing & Appearance

  • Added first-pass inline table editing for SQL databases, including row update, insert, and delete actions for table browse views.
  • Table metadata is now used to detect primary keys and build safer row predicates for edits and deletes.
  • Added a new Glassy Terminal appearance mode for a transparent, blurred, Linux-terminal-inspired desktop theme.
v1.0.1

Amber Anchor

2026-06-02

This release introduces critical SSH stability improvements, a connection queuing manager to prevent session exhaustion, custom toggles, password visibility eye toggles, multi-architecture macOS build support, Tailwind CSS v4 styling migration, and significant CPU optimization by removing redundant periodic uptime monitoring loops.

SSH Stability & Queuing

  • Implemented a sequential FIFO Promise queue (connectionQueues) to serialize remote execution requests and prevent MaxSessions channel open failures.
  • Added SSH keepalive heartbeats (keepaliveInterval: 10000, keepaliveCountMax: 3) to automatically teardown dead or timed-out connection sockets.
  • Cleared connection queue state upon socket closure, errors, or idle timeout evictions to prevent reference memory leaks.
  • Completely removed the 60-second periodic background uptime monitoring checks to eliminate unnecessary SSH load on servers.

Visual Refinements & Controls

  • Integrated an interactive eye icon visibility toggle for masked server passwords under the Authentication table column.
  • Replaced native browser checkboxes across server configuration forms, Docker views, and settings with sleek custom React buttons.
  • Fixed bottom terminal active checks to prevent active SSH stream sessions from unmounting and disconnecting during drawer toggles.
  • Migrated custom UI styling and theme colors to Tailwind CSS v4 design specifications.

Deployment & Core Infrastructure

  • Configured explicit multi-arch macOS targets supporting both Apple Silicon (ARM64) and Intel (x64) architectures.
  • Refined Certbot automatic SSL detection and status verification logic for server domains.
  • Optimized Tor SOCKS5 proxy toggle defaults for SSH connections.
v1.0.0

Cobalt Catalyst

2026-05-27

The first full release of Serop — a desktop server management suite built on Electron, React, and SSH. Cobalt Catalyst introduces an auto-updating notification system, a custom app logo icon, and a default-disabled feature toggling mechanism.

Auto-Update System

  • GitHub Releases API silent check to automatically check for new versions on launch
  • Non-intrusive floating toast alerts for new release tags with an expandable changelog body
  • Persistent version dismissals stored in local storage to prevent duplicate alerts
  • Check for Updates option inside the application Help menu

Visual Identity & Custom Icon

  • New custom-designed squircle brand logo mark deployed at all standard system icon sizes
  • Support for dynamic Dock icon loading at runtime during macOS development

Disabled-by-Default Feature Suite

  • All optional server and deployment modules disabled by default on clean installations
  • On-demand opt-in control panel allowing users to only turn on features they require

SQL Query Runner

  • Monaco Editor input with SQL syntax highlighting for MySQL and PostgreSQL
  • Run button that executes queries over the SSH-tunneled database connection
  • Paginated results table with row count and execution time display
  • Inline error reporting for database and connection failures
  • Autocomplete for table names pulled from the live schema

Git Deployment Pipeline

  • Server + project directory selector with one-click Deploy action
  • SSHes in and runs git pull, npm install / pip install, migrations, and service restart
  • Supports pm2 restart and systemctl restart as service managers
  • Real-time output streamed into the integrated terminal during deployment
  • Terminal input is locked while a deployment is in progress

Deployment History & Rollbacks

  • All deploys logged to a local SQLite table (timestamp, branch, commit hash, status, output)
  • Per-server/project deploy history list with colored success/failure badges
  • Visual log viewer with expandable terminal output per deploy entry
  • Rollback button — SSHes in, runs git checkout <commit>, and restarts the service

Terminal Snippet Library

  • Save commands with a title, description, and body to a persistent local library
  • Searchable side panel with instant fuzzy filtering across all snippets
  • Click a snippet to paste it directly into the active terminal
  • Variable placeholder support: {{domain}}, {{port}}, etc. — prompts for values before pasting
  • Copy-to-clipboard button on every snippet card
  • Seed snippets included out of the box (nginx reload, pm2 status, docker prune, etc.)

Core Infrastructure

  • Electron + React + TypeScript foundation with Vite bundler
  • SSH connection manager with EC2 key-pair, password, and Cloudflare Tunnel modes
  • Tor SOCKS5 proxy support for anonymous SSH connections
  • Remote file explorer with Monaco editor, uploads, downloads, and search
  • Docker container monitor — logs, rebuilds, and service status management
  • Server admin panel with OS info, service controller, and performance charts
  • Config creator wizards for systemd units and Nginx reverse-proxy blocks
  • AI assistant integration for shell diagnostics and query optimization
  • Persistent markdown notes synced with the Monaco editor workspace
