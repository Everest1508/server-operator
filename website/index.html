Everything in one workspace

Built for developers who live in terminals and compose files — with optional AI-assisted deploy suggestions and Tor/SOCKS support when you need it.

🔐

SSH servers

Add servers with host, username, and private key or password. Optional project path and working directory for commands. Test connection before you commit.

📂

Remote file tree

Browse the server filesystem from the sidebar: open Dockerfiles, compose files, env files, and edit them in the editor area with familiar keyboard shortcuts.

✎

Monaco editor

Same editor engine as VS Code for syntax highlighting and a comfortable editing experience on YAML, Dockerfiles, shell scripts, and more.

⬡

Docker overview

List containers from docker ps -a, inspect status, and jump into logs or terminal workflows for the selected server.

📜

Compose logs

Tail Docker Compose logs in the bottom panel with optional service filter and line count. Stream logs over SSH when you need live output.

🚀

Deploy & presets

Run deploy commands such as git pull && docker compose up -d --build with one click. Save time with sensible presets for common flows.

⌨

Integrated terminal

Full xterm.js terminal over SSH: resize-aware, fit-to-panel, and ready for interactive sessions on the remote host.

🧅

Proxy & Tor

Optional global SOCKS proxy (e.g. Tor on 9050 or Tor Browser on 9150). Per-server toggle to connect directly when the host is clearnet-only.

✨

Groq-powered assist

Optional Groq API key (stored locally) for AI-suggested deploy commands and helpers in the deploy flow — your key never leaves your machine except to Groq’s API.

⚙

Config generators

Scaffold nginx, Docker Compose snippets, and related config from structured forms — paste the output straight into your server tree.

🖥

Local workspace mode

Open a real folder from your own machine and use Server Operator against local files, local Docker, compose logs, databases, terminal workflows, and project shortcuts.

🎤

Voice input (optional)

Voice-to-text via Groq Whisper where supported — handy for long deploy notes or command dictation from the desktop app.

Project shortcuts for AI agents

Server Operator supports project-local command shortcuts in .server-operator/*.serop. Use the initializer to scaffold this folder, then let coding agents maintain these files in each repository.

Initialize a project

Creates deploy.serop, ops.serop, custom.serop, and AI context files so humans and agents follow the same structure.

$ curl -fsSL https://server-operator-zeta.vercel.app/init-server-operator.sh | sh
PS> iwr https://server-operator-zeta.vercel.app/init-server-operator.ps1 -UseBasicParsing | iex
$ npm run serop:init -- --path /path/to/project
$ serop .
$ npx server-operator-init --interactive --path .
$ npm i -D server-operator && npx server-operator-init --path .
# Add/update shortcuts in .server-operator/*.serop

What’s New in 2.0.1

v2.0.1

Glass Harbor

2026-06-12

Local Workspace Mode

  • Open a real local folder without SSH.
  • Use Docker, logs, database tools, terminal, deploy, and `.serop` shortcuts in that folder.
  • Launch directly into a folder with serop ..

Deploy Assistant

  • Groq deploy chat now gives explanations plus runnable commands.
  • Better project-path awareness, command parsing, and fallback handling for rate-limited models.
  • Cleaner chat cards and sidebar-based project/context/shortcut controls.

Database & Theme

  • Inline SQL table row editing for update, insert, and delete workflows.
  • New glassy terminal-style theme option inside Settings.
